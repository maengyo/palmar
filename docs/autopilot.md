# palmer 자율 개발 골

너는 이 저장소에서 palmer 를 만든다. 사람은 자리에 없다.
**정본은 저장소다** — 이 문서보다 저장소가 앞선다. 매 사이클 처음에 `AGENTS.md` 를 다시 읽는다.

## 무엇을 만드는가

돌고 있는 코딩 에이전트들을 위한 공간형 캔버스. 터미널이 놓아둔 자리에 그 크기로 있고,
각각이 **일하는 중 · 나를 기다림 · 끝남 · 대기** 로 보인다. 브라우저 탭을 닫아도 세션은 산다.
런타임은 우리 것이다 — PTY 를 띄우고, 바이트를 옮기고, CLI 훅을 받고, 자리를 기억한다. 그 이상은 아니다.

## 이미 정해진 것 (다시 정하지 마라)

- **언어: 파이썬, 바닥 3.9.** `/usr/bin/python3` 가 3.9.6 이고 그게 "설치 0" 의 근거다. 3.10+ 문법 금지.
  **Bun 으로 옮길 수 있게 짜라** — 프로토콜을 `docs/protocol.md` 에 고정하고, 터미널 상태를 데몬 밖에 두고,
  표준 라이브러리로 되는 것은 표준으로 한다.
- **데몬은 재시작하지 않는다(⑦=b).** 핸드오프를 만들지 마라. 되긴 된다 — 안 하기로 한 것이다.
  오래 도는 것을 전제로 짜라. 누수는 재시작으로 안 씻긴다.
- **재접속(⑨):** 에이전트는 SIGWINCH 흔들기, 셸은 링버퍼 재생. **링버퍼 pane 당 256KB.**
  alt-screen(`ESC[?1049h`) 안에서는 버퍼를 키우지 않는다.
- **훅은 PATH shim 이 붙인다.** `~/.palmer/bin/claude` 가 진짜 `claude --settings <pane별 파일>` 을 exec 한다.
  사용자의 `~/.claude/settings.json` 은 어떤 이유로도 쓰지 않는다. `--settings` 가 병합임은 실측됐다.
- **palmer 는 셸만 연다.** 도구 목록 없음. 데몬이 `$SHELL` 을 박아 쓴다 — **클라이언트가 명령을 못 고른다.**
- **화면:** 왼쪽 터미널 목록(기다리는 것이 위), 가운데 캔버스, 오른쪽 디렉터리(폴더만, 게으르게).
  겹치지 않는다 — 새 창이 옆을 민다(termcanvas 식). 카메라 줌 없음. 확대 보기 있음. 테마 둘.
  디자인 정본은 대화 아티팩트 "palmer" 와 `decisions.md` 의 "디자인" 절.
- **보안(#29):** `127.0.0.1` 밖으로 안 연다, host 옵션 없음. 웹소켓은 `Origin` 검사 + 토큰.
  `~/.palmer/` 는 0700. 경로 검사는 `is_relative_to`. pane 식별자는 추측 불가 토큰. `/report` 는 제품에 없다.
- **언어 규칙:** 커밋 메시지·README·이슈 제목은 **영어**. `docs/` 는 한국어. README 를 고치면 `README.ko.md` 도 고친다.

## 아직 사람이 정할 것 — 절대 네가 정하지 마라

**① 웹 스택 · ③ 좌표 저장 위치 · ④ 앱 출시 시점 · ⑥ 신호등 색 매핑 · ⑧ codex 상태 경로 · ⑩ 밀 자리 없을 때.**
이 중 하나에 막히면: 이슈에 **판단 재료를 정리한 댓글**을 남기고(양쪽 근거, 잰 것, 안 잰 것, 네 의견 한 줄),
보드에서 `Blocked` 로 두고, 다른 열린 항목으로 간다. **열린 항목이 전부 이 여섯에 막혀 있으면 루프를 멈춘다.**

## 실물이 먼저다

**매 사이클 끝에 사용자가 직접 돌려 볼 수 있는 것이 있어야 한다.** (2026-09-07 밤, 사용자)
문서만 늘어나는 사이클은 실패다. 스파이크·설계·결정은 실물을 만들기 위한 것이고, 실물이 곧 검증이다.

- **`README.md` 의 "Try it" 절을 항상 맞춰 둔다** — 지금 이 순간 무엇을 어떻게 띄우는지 명령 한 줄과,
  띄우면 무엇이 보이고 무엇이 아직 안 되는지. 사용자는 그 절만 보고 시작할 수 있어야 한다.
  `README.ko.md` 에도 같은 절("해 보기")을 둔다.
- 시작 명령은 `python3 server/palmerd.py` 하나로 수렴시킨다. 인자 없이 뜨고, 브라우저 주소를 찍는다.
- **깨진 상태로 사이클을 끝내지 마라.** 새 기능이 미완이면 켜지지 않게 두고, 지금 도는 것은 계속 돌아야 한다.
- 사용자가 써 보고 남긴 말(이슈 댓글, 대화)은 어떤 측정보다 우선하는 입력이다. 다음 사이클 맨 앞에 둔다.

## 사이클 — 이 순서를 지킨다

1. **보드에서 `Next` 하나를 집는다.** 없으면 `Todo` 중 의존이 풀린 것을 `Next` 로 올린다. `Next` 는 항상 하나다.
   `In Progress` 로 바꾸고 시작한다.
2. **이슈 본문을 읽고, 관련 `decisions.md` 절과 스파이크를 읽는다.** 이미 도는 코드가 있으면 그걸 출발점으로 한다
   (`docs/spikes/2026-09-07/pipeline/py/server.py` 290줄이 데몬의 뼈대다).
3. **만든다.** 제품 코드는 `server/`(데몬)와 `web/`(브라우저)에 둔다. 스파이크는 `docs/spikes/` 그대로 둔다.
   기능 하나가 끝나면 **실행해서 확인한다.** "될 것이다" 는 결과가 아니다.
   끝나면 **README "Try it" 을 갱신한다** — 사용자가 지금 뭘 할 수 있는지.
4. **재야 할 것은 잰다.** 성능·메모리·지연을 주장할 때는 스크립트로 재고 숫자와 조건을 적는다.
   못 잰 것은 **"안 잰 것"** 으로 명시한다. 1회 측정은 1회라고 쓴다.
5. **교차 검토를 돈다** (아래 "검증").
6. **기록한다.** 결정이 바뀌었으면 `decisions.md` 먼저, 그 다음 `roadmap.md`. 새로 잰 것은 `own-runtime.md`.
   README 를 건드렸으면 두 판 다.
7. **커밋·푸시는 사람이 요청할 때만 한다.** (2026-09-07 밤, 사용자) 작업 트리에 두고, 무엇이 바뀌었는지
   `docs/roadmap.md` "지금 어디인가" 에 적어 둔다. 요청이 오면 영어 커밋 메시지로, 트레일러
   `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` 과 `Claude-Session:` 줄을 붙인다.
8. **이슈를 닫는다 — 무엇으로 답했는지 댓글로.** 닫기만 하지 않는다. 보드 상태를 `Done` 으로.
   (이슈·보드 갱신은 커밋이 아니므로 바로 한다.)
   다음 항목을 `Next` 로 올린다. 1 로 돌아간다.

## 멀티 에이전트 — 어떻게 나누는가

**한 워크플로에 에이전트 10개를 넘기지 마라.** 2026-09-04 에 105개짜리가 세션 한도를 쳤고, 9개짜리도 한 번 쳤다.
큰 항목은 순차로 나눠 여러 워크플로로 돈다.

- **만들기:** 항목이 서로 안 겹치는 파일 셋 이상으로 갈리면 병렬(worktree 격리), 아니면 하나가 순차로.
- **검토:** 만든 것마다 **관점이 다른 검토자 셋** — 정확성(실제로 돌려 본다) · 보안(#29 목록에 대고) ·
  결정 위반(`AGENTS.md` 금지 목록과 "이미 정해진 것" 에 대고). 같은 관점 셋보다 다른 관점 셋이 더 잡는다.
- **검증:** 검토가 낸 지적은 **반박 시도**를 거친다 — 근거가 약하면 버린다. 살아남은 것만 고친다.
- 스파이크는 에이전트 하나가 끝까지 한다. 나누면 조건이 어긋난다.

## 검증 — Codex 교차 검토

**항목 하나를 닫기 전과, 결정을 바꾼 뒤에** Codex 로 본다. 자기 검토는 같은 자리에서 같은 것을 놓친다.

```
codex:rescue 스킬 (또는 node ~/.claude/plugins/cache/openai-codex/codex/1.0.6/scripts/codex-companion.mjs task ...)
```

부탁하는 것: "이 커밋(들)을 `AGENTS.md`·`decisions.md` 에 대고 검토해라. 정해진 것을 어긴 곳, 안 잰 것을 잰 것처럼
쓴 곳, 사람 몫의 결정을 내가 정해 버린 곳, 보안 목록(#29) 위반을 찾아라."

**Codex 가 토큰 한도·요금 한도·인증 오류로 실패하면 — 건너뛴다.** 커밋 메시지나 이슈 댓글에
`Codex review skipped: <이유>` 한 줄을 남기고 계속 간다. **막히지 마라.** 다음 사이클에 다시 시도한다.
Codex 가 지적한 것 중 **틀린 지적은 틀렸다고 적고 넘긴다** — 이전에 12개 중 1개가 틀렸었다.

## 하지 마라

- `AGENTS.md` 의 "하지 말아야 할 것" 전부. 특히: 카메라 줌, 핸드오프, 겹치기 설정, 사용자 settings.json 쓰기,
  클라이언트가 준 명령 실행, 신호등 색(초록·호박·빨강·회색)을 다른 데 쓰기, 화면 정규식으로 상태 정하기.

- 저장소 밖 파일을 고치는 것. `~/.claude/`, `~/.palmer/` 는 코드가 런타임에 만드는 것이지 네가 손대는 것이 아니다.
- `git push --force`, 히스토리 재작성, 브랜치 삭제. 문제가 있으면 새 커밋으로 고친다.

- "아직 아무것도 만들지 않았다" 류의 README 문장을 사실과 다르게 두는 것. 코드가 생기면 README 를 맞춘다.
