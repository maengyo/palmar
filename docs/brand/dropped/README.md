# 접은 것들

지우지 않았다. 무엇을 해봤고 왜 접었는지가 다음 사람에게 필요하다.

## 심볼 — 전부 접었다 (2026-09-08, 사용자)

로고는 **워드마크 하나로 간다.** 네모 자리에는 심볼 대신 낱말의 첫 글자(`../p.svg`)를 쓴다.

| 파일 | 무엇이었나 | 왜 접었나 |
| --- | --- | --- |
| `palmar-mark.svg` | 오므린 손 안에 창 셋 | **바구니로 읽힌다.** 엄지로 넣은 왼팔 높이 차이가 너무 약했다 |
| `palmar-mark-small.svg` | 위의 16px 판 | 위와 같음 |
| `mark-a-place.svg` | 점 격자 위에 놓인 창 하나 | 정확하지만 "캔버스 앱"이라고만 말한다 |
| `mark-b-panes.svg` | 미니맵 그대로, 창 셋 | 대시보드 아이콘 계열, 남과 비슷하다 |
| `mark-c-p.svg` | 창으로 만든 `p` | 워드마크의 `p` 와 하는 말이 겹친다 |
| `mark-d-palm.svg` | 손바닥과 손가락 | 손을 안 보면 이퀄라이저로 읽힌다 |
| `mark-e-dot.svg` | 켜진 점 하나 | 단독으로는 이름을 뜻하지 못한다 |
| `lockup.svg`, `palmar-lockup.svg` | 마크 + 워드마크 | 마크가 없으니 묶을 것이 없다 |

**공통된 이유가 하나 있다.** 여섯 개가 전부 *테두리 안에 타일을 넣는* 한 가지 발상의 변주였다.
다른 발상 없이 변주만 늘렸다는 것이, 하나씩의 약점보다 큰 문제였다.

## 워드마크 — 하나 접었다

| 파일 | 무엇이었나 | 왜 접었나 |
| --- | --- | --- |
| `wordmark-hand.svg` | `m` 의 봉우리를 손가락처럼 어긋내고 `l` 꼬리를 엄지로 | **말해줘야 보인다.** 안 말하면 삐뚤한 `m` 이다 |

이 파일들은 생성기(`docs/brand/wordmark.py`)가 더 이상 뽑지 않는다. 손으로 옮겨둔 그대로다.
