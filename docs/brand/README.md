# 브랜드 — 워드마크

**로고는 워드마크 하나다. 심볼은 없다.** 왜 없는지는 [`dropped/README.md`](dropped/README.md).

전부 [`wordmark.py`](wordmark.py) 가 뽑는다. 저장소 뿌리에서:

```
python3 docs/brand/wordmark.py
```

**손으로 찍은 좌표는 없다.** 그 파일 맨 위의 상수(획 두께·기준선·반지름·곁여백)만이 정본이고,
글자는 전부 거기서 계산된다. 두께를 바꾸고 싶으면 `W` 를 고치고 다시 돌린다.

## 왜 폰트가 아니라 그린 글자인가

README 대로 **JetBrains Mono 웹폰트는 받아두지 않았다.** 로컬에 없으면 시스템 모노로 떨어지므로,
지금 상단 막대의 `<span class="brand">palmar</span>` 는 기계마다 다른 얼굴로 뜬다.
경로로 그린 글자는 떨어질 데가 없다.

## 점 규칙

`palmar` 에는 **똑같은 크기의 닫힌 속이 셋** 있다 — `p` · `a` · `a`. 셋 다 같은 원(반지름 18.5)이라
**같은 창 셋**으로 읽힌다. (`palmer` 로는 안 되던 일이다: 거기서는 `e` 의 속이 반달이라 셋이 한 벌이 되지 못한다.)

**점 셋은 세션이 셋이라는 뜻이 아니다.** 낱말이 가진 속이 셋일 뿐이고, 말하려는 것은 둘뿐이다 —
*여럿을 쥐고 있다*, 그리고 *그중 하나가 너를 기다린다*. 게이지가 아니다.

- **앰버는 하나이거나 없다.** 몇 개가 기다리든 하나만 켠다. 캔버스 탭 규칙과 같다(탭도 점 하나만 단다).
- 앰버가 앉는 자리는 **마지막 속**(두 번째 `a`)이다 — 눈이 낱말 끝까지 간다.
- 조용할 때는 `wordmark-quiet.svg`. 두 판은 **같은 파일에서 점 하나의 색만** 다르다.

## 색 — ⑥ 을 앞질러 정하지 않았다

앰버는 **신호등의 "기다린다" 색이다. 로고가 따로 정하지 않는다.**
SVG 는 `fill="var(--st-wait, #d99a2b)"` 로 쓰므로,

- 앱 안에 **인라인**되면 `style.css` 의 `--st-wait` 을 그대로 따른다(밝은 판 `#a8730f`, 어두운 판 `#e2a63a`).
- 파일 하나로 열거나 `<img>` 로 부르면 뒤의 값으로 떨어진다.

⑥(신호등 색 매핑)이 정해지면 `style.css` 한 곳만 고치면 로고까지 따라온다. **새 색을 만들지 않았다.**
잉크는 전부 `currentColor` 라 밝은 바탕·어두운 바탕을 같이 탄다.

## 규칙

- 곁여백은 **x-높이의 절반(24)**. 그 안에 다른 것을 넣지 않는다.
- 워드마크는 **12px 높이**까지. 그 아래는 `p` 로 바꾼다.
- 늘리거나 좁히지 않는다. 기울이지 않는다.
- 잉크 색을 정하지 않는다 — 바탕이 정한다.
- **앰버를 둘 이상 켜지 않는다.**
- 폰트로 다시 치지 않는다. 경로다.

## 아직 안 한 것

- 앱에 안 붙였다. `palmar/web/index.html` 의 `<span class="brand">palmar</span>` 와
  빈 파비콘(`<link rel="icon" href="data:,">`)이 그대로다.
- **로고를 실제 상태에 물리는 것**은 제안 단계다. 두 판이 점 하나의 색만 다르므로,
  뭔가 답을 기다릴 때만 상단 막대와 파비콘이 앰버로 바뀌게 할 수 있다. ⑥ 과 같이 정할 일이다.
