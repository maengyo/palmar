## 보드 읽는 법

| 필드 | 뜻 |
|---|---|
| **Status** | `Next` 지금 시작할 하나 · `Todo` 시작할 수 있음 · `Blocked` 다른 항목을 기다림 · `In Progress` · `Done` |
| **Target** | 목표일. 아래 순서를 **주 4시간**으로 쌓아 계산했다 |
| **Hours** | 예상 시간. Target 의 근거다 |
| **Milestone** | 네 단계. 단계 마감이 항목 Target 의 상한이다 |
| **Labels** | `P0`~`P3` 우선순위 · `spike` 기능이 아니라 질문 · `needs-decision` 사람의 판단 대기 |

**고치는 순서.** 날짜를 바꿀 때는 **마일스톤을 먼저** 고치고 항목 Target 을 맞춘다 — 마일스톤이 정본이다.
결정이 바뀌면 **`decisions.md` 를 먼저** 고치고 여기를 따라 고친다 — 이 문서는 정본이 아니다.
이슈를 닫을 때는 **무엇으로 답했는지**를 댓글에 남긴다. 닫기만 하지 않는다.

**지금 `Next` 는 하나뿐이다** — #29(보안). 여러 개를 동시에 `Next` 로 두지 않는다.

## 지금 어디인가

**웹으로도 쓰고, 창으로도 쓴다.** `palmar` 한 줄이면 데몬이 뜨고 브라우저가 열린다. 창이 필요하면
`app/` 의 700KB 짜리 실행파일 하나가 같은 데몬을 같은 화면으로 보여 준다 — Electron 이 아니고,
OS 가 이미 가진 웹뷰를 쓴다. 둘은 **한 데몬을 보는 두 창**이고, 동시에 켜도 같은 작업판이다.
**러스트 없이 받아 쓸 수 있다** — CI 가 리눅스 x86-64 와 **맥 유니버설**(인텔+애플실리콘 한 파일,
macOS 11 이상)을 만든다. 맥 것은 09-13 에 붙였다(`app-mac.yml`). 아직 `.app` 번들도 서명도 아니다(#12).

**WSLg 에서 돈다(2026-09-11, 실측).** 윈도우에서 WSL 안에 띄우면 리눅스 GUI 프로그램 하나로
뜬다. 그날 한글 표시·한글 입력·합성 지연·레일 접기·제목줄 두께를 다 고쳤다 — `docs/wslg.md` 가
처음 설정하는 사람을 위한 안내다. **네이티브 윈도우는 아직이다**(#29).

**작업판이 재시작을 넘긴다.** 데몬이 죽어도 터미널의 이름과 마지막 경로를 기억했다가, 다시 뜨면
"여덟 개 다시 열까" 하고 묻는다. 셸 자체는 안 살아난다 — 그건 ⑦=b 로 정한 것이다.

**신호등이 설정 없이 켜진다.** 에이전트가 창 제목에 싣는 바쁨을 데몬이 읽는다. codex 도, 처음 보는
에이전트도 훅 없이 켜진다.

**창은 겹치지 않는다(2026-09-13).** 창을 끌어다 놓거나 키워서 다른 창에 닿게 하면 거기 있던 창이
비켜난다 — 겹친 만큼만, 제일 가까운 쪽으로, 그게 또 세 번째에 닿으면 이어서. 밀려서 화면 밖으로
나가도 왼쪽 목록의 `↗ off` 와 미니맵이 잡아 준다. 아래 한 줄이 몇 개 움직였는지 말하고 `undo` 를 준다.

**시험이 150개다.** 파이썬 표준 라이브러리만 쓴다(pytest 없음). `pure 38 · daemon 51 · browser 48 ·
app 9 · install 4` — 브라우저 것은 진짜 Chrome 을 DevTools 프로토콜로 몬다. **CI 가 매 push 마다
돌린다**(3.9·3.13, 약 3분). 리눅스 창 빌드와 윈도우 프로브는 따로 돈다.

**문서가 틀리면 그 위의 판단이 다 틀어진다.**

## 순서 — 무엇이 무엇을 막는가

화살표는 **"이게 저걸 막는다"** 다. 왼쪽이 끝나야 오른쪽을 할 수 있다.

**Phase 1·2·3 의 관문은 다 열렸다.** ②(언어)·⑦(재시작)·⑧(codex)·보안·데몬·레일·신호등이 전부
끝나서, 예전 그래프의 화살표는 하나도 안 남았다. 지금 막혀 있는 것은 둘뿐이다 — **사람이 정할 것**과
**내보내기**.

```
사람이 정해야 움직이는 것 (코드가 막는 게 아니다)
   #4 ⑥ 신호등 색 ─→ 모름·에이전트 없음·오류를 어떻게 보일지
   #2 ③ 좌표      ─→ 데몬으로 옮길지, 브라우저에 둘지
   #21 오른쪽 레일 ─→ 디렉터리로 둘지, 최근 터미널로 바꿀지

내보내기 (여기만 사슬이 있다)
   #23 PyPI·공개 ──→ #12 서명·자동 업데이트·번들 ──→ #3 ④ 앱은 언제
        └─→ install.sh 의 한 줄이 진짜가 된다

혼자 서는 것
   ~~CI 가 시험 137개를 돌린다~~  **됐다 (09-11)** — 붙인 날 맥에서만 통하던 시험 둘을 잡았다
   #29 네이티브 윈도우          (제일 크다)
   ~~#8  밀어내기~~            **됐다 (09-13)** — 시험 열셋이 지킨다
   #13 설정 화면 · 빈 캔버스 안내
```
