**통합해서 끝까지 돌린 것 (2026-09-08 저녁, 진짜 8801, `/usr/bin/python3` 3.9.6, 헤드리스 크롬 152 +
CDP, 브라우저 탭 둘):** 데몬 쪽 43/43 · 브라우저 쪽 51/51, 0 실패.

- **닫기:** 타일의 ×→확인→`DELETE` 한 번→pane 프로세스 `ps` 로 죽음 확인→타일과 목록 행이 사라지고
  **둘째 브라우저도 같이** 사라진다(수 6→5→4가 두 브라우저에서 같다). 목록 행에서도 같다.
  Esc·Cancel 은 `DELETE` 를 **0건** 낸다. 지우는 길은 `gone` 하나뿐이다.
- **뿌리:** `GET /api/dirs` 가 `['/Users/me']` 만 낸다. uid 를 갈아 끼워 재 보면 `getuid()=0` 일 때만
  root 소유 `/Users/Shared` 가 들어오고 `getuid()=999` 면 `$HOME` 만 남는다 — 규칙이 진짜 uid 다.
  `POST /api/sessions cwd=/Users/Shared` 는 `400`.
- **캔버스 묶기:** `api(3, 기다림 1)` 을 접으면 캐럿 `▸`, 머리글 수는 **3 그대로**, 기다리는 줄 하나만
  남고(`display:grid`, `offsetParent` 있음, `elementFromPoint` 가 그 줄을 짚는다) **목록 전체의 첫 줄**,
  아래에 `+2 more, collapsed`. 새로 고쳐도 그대로. 접힌 채로 그 줄에서 바로 닫힌다.
- **회귀:** 세션 만들기·`/pty` 붙기·브라우저에서 친 명령의 에코·오프셋 재접속(`from=받은 만큼` → 재생 0,
  `from=0` → 251바이트 재생)·훅 `idle`→`working`→`waiting`→`done`→`seen`→`idle`·`waiting` 은 안 꺼짐·
  탭 순서 바꾸기가 두 브라우저에·미니맵이 `transform` 으로 스크롤을 따라감·캔버스 만들기/지우기/`409` 둘.

**통합에서 잡아 고친 것 하나 (`web/app.js` `renderList`).** 목록 행의 닫기 확인이 열려 있는데
**다른 세션의 훅 방송**이 하나 오면, 목록을 다시 지으면서 그 줄의 **포커스가 `body` 로 떨어졌다.**
줄은 그대로 보이는데 Enter 가 `Close` 를 안 누르고(`DELETE` 0건) Escape 도 그 줄이 아니라 document 로
갔다 — `buildItem` 안에서 부르는 `focus()` 는 그 행이 아직 `document` 에 안 붙어 있어 무시된다.
훅·resize 방송은 늘 오므로 **키보드로 닫는 길이 사실상 없었다**(#31 ④ 가 `<button>` 을 쓴 이유가 그것이다).
다시 짓기 전에 그 줄이 포커스를 갖고 있었는지 재고 다 붙인 뒤에 돌려주도록 고쳤다 — 안 갖고 있었으면
건드리지 않는다(검색칸·터미널의 포커스를 뺏지 않는다). 고친 뒤 타일 쪽·목록 쪽 둘 다 방송을 맞고도
Enter 로 닫힌다.

**같이 맞춘 것 (`web/dev-stub.py`).** 스텁의 `roots()` 에 uid 검사가 빠져 있어 `protocol.md` 의
"뿌리" 문단과 어긋나 있었다(스텁은 `/api/dirs` 에서 진짜 파일시스템을 읽는다 — WSL 이면 `/home/bb` 가
그대로 떴을 것이다). 데몬과 같은 술어를 넣었다.

**안 잰 것:** 진짜 WSL 에서의 `/home/bb` 는 이 기계에 없어 **root 소유 `/Users/Shared` 로 대신 쟀다**
(같은 성질: 내가 아닌 uid 가 가진, 읽기·실행 가능한 디렉터리). 색·간격·읽히는가는 여전히 사람이 볼 것이다.
