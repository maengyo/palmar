## 지금 어디인가

**웹으로도 쓰고, 창으로도 쓴다.** `palmar` 한 줄이면 데몬이 뜨고 브라우저가 열린다. 창이 필요하면
`app/` 의 700KB 짜리 실행파일 하나가 같은 데몬을 같은 화면으로 보여 준다 — Electron 이 아니고,
OS 가 이미 가진 웹뷰를 쓴다. 둘은 **한 데몬을 보는 두 창**이고, 동시에 켜도 같은 작업판이다.
**러스트 없이 받아 쓸 수 있다** — CI 가 리눅스 x86-64 와 **맥 유니버설**(인텔+애플실리콘 한 파일,
macOS 11 이상)을 만든다. 맥 것은 09-13 에 붙였다(`app-mac.yml`). 아직 `.app` 번들도 서명도 아니다(#12).

**WSLg 에서 돈다(2026-09-11, 실측).** 윈도우에서 WSL 안에 띄우면 리눅스 GUI 프로그램 하나로
뜬다. 그날 한글 표시·한글 입력·합성 지연·레일 접기·제목줄 두께를 다 고쳤다 — `docs/wslg.md` 가
처음 설정하는 사람을 위한 안내다.

**네이티브 윈도우에서 신호등이 움직인다(2026-09-18, 실측).** PowerShell 머리말 하나가 세 가지를
한다 — `claude` 의 훅을 붙이고, `cd` 를 따라가게 제목에 경로를 쓰고, OSC 133 으로 "명령이 시작·
끝났다" 를 말한다. 그 전까지 윈도우에는 셋 다 없었고, 막고 있던 것 중 둘은 기능이 없어서가 아니라
**POSIX 코드가 거기서 조용히 아무것도 안 하고 있어서**였다(PATH 구분자가 `:` 로 박혀 있었고, shim 이
실행될 수 없는 모양이었다). `cd` 는 그 김에 **세 OS 전부에서** 처음으로 레일에 반영됐다 — 그때까지
레일은 판을 만든 폴더 이름을 평생 말하고 있었다. **게이트는 아직 있다**(#29).

**떨어뜨린 파일이 열린다(2026-09-18).** Finder·탐색기에서 끌어다 놓으면 뷰어가 뜬다. 페이지는
파일의 **위치를 볼 수 없어서**(윈도우는 `text/uri-list` 조차 안 준다) 이름·크기·수정시각으로 찾는다 —
홈, 이미 연 파일들의 폴더, 붙어 있는 볼륨. 셋이 다 맞는 파일이 **하나일 때만** 연다.

**작업판이 재시작을 넘긴다.** 데몬이 죽어도 터미널의 이름과 마지막 경로를 기억했다가, 다시 뜨면
"여덟 개 다시 열까" 하고 묻는다. 셸 자체는 안 살아난다 — 그건 ⑦=b 로 정한 것이다.

**신호등이 설정 없이 켜진다.** 에이전트가 창 제목에 싣는 바쁨을 데몬이 읽는다. codex 도, 처음 보는
에이전트도 훅 없이 켜진다.

**창은 겹치지 않는다(2026-09-13).** 창을 끌어다 놓거나 키워서 다른 창에 닿게 하면 거기 있던 창이
비켜난다 — 겹친 만큼만, 제일 가까운 쪽으로, 그게 또 세 번째에 닿으면 이어서. 밀려서 화면 밖으로
나가도 왼쪽 목록의 `↗ off` 와 미니맵이 잡아 준다. 아래 한 줄이 몇 개 움직였는지 말하고 `undo` 를 준다.

**2026-09-15 — 창이 먼저고, 릴리스가 있고, 보안 점검을 했다.** `palmar` 는 이제 창을 연다: 맥은 palmar
의 창(WKWebView), 다른 곳은 설치한 앱(PWA) → 크로미엄 앱 모드(기본 브라우저; 윈도우엔 Edge 가 늘
있다) → 창 → 탭 순서 — exe 없이도 윈도우에 창이 뜬다(실측: Edge 앱 모드). **v0.1.1 릴리스**가 맥
유니버설·리눅스 x86-64 창과 `SHA256SUMS` 를 갖고 있고, `install.sh` 는 릴리스에서 창을 받아 해시를 대조한다
— 산출물이 90일에 사라지는 문제는 이걸로 끝. 저장소는 **공개**라 한 줄 설치가 밖에서 된다; 파이썬이
없으면 설치 스크립트가 구해 온다. WSL 옆의 윈도우(같은 포트·같은 localStorage·윈도우 PATH 없음)와 큰
파일·토스트·글꼴 라운드도 이날이다. **보안 점검**(네 경계, 반박자 검증): `run/url` 은 살아 있는 데몬만,
키는 명령줄에 안 오름, 런처는 스크립트 경로, CSP, 열기≠실행, 심링크, 임시 파일 이름 — `decisions.md ②-1`.

**시험이 361개다.** 파이썬 표준 라이브러리만 쓴다(pytest 없음) — 브라우저 것은 진짜 Chrome 을 DevTools
프로토콜로 몬다. **CI 가 매 push 마다 돌린다**(3.9·3.13). 리눅스 창 빌드·맥 창 빌드·윈도우 프로브·릴리스는

## 순서 — 무엇이 무엇을 막는가

화살표는 **"이게 저걸 막는다"** 다. 왼쪽이 끝나야 오른쪽을 할 수 있다.

**Phase 1·2·3 의 관문은 다 열렸다.** ②(언어)·⑦(재시작)·⑧(codex)·보안·데몬·레일·신호등이 전부
끝나서, 예전 그래프의 화살표는 하나도 안 남았다. 지금 막혀 있는 것은 둘뿐이다 — **사람이 정할 것**과
**내보내기**.

```
사람이 정해야 움직이는 것 (코드가 막는 게 아니다)
   #4  ⑥ 신호등 색  ─→ 모름·에이전트 없음·오류를 어떻게 보일지
   #28 두 브라우저   ─→ 한 판을 볼 때 누구 크기가 이기는가
   #31 윈도우 범위   ─→ %USERPROFILE% 밖에도 터미널을 열 것인가
   (reports.md) 모으기 버튼 · 그룹 이름 · 캔버스 메모 · 리소스 표시

   #23 PyPI·공개 ──→ #12 서명·자동 업데이트·번들 ──→ #3 ④ 앱은 언제
        └─→ install.sh 의 한 줄이 진짜가 된다
   제일 앞이 결정이다 — "공개할 것인가"
```
