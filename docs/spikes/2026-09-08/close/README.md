# #31 — 닫기 · 남의 홈 · 캔버스로 묶기: 재현과 증명 (2026-09-08)

이 폴더는 **#31 을 두 번째로 검토할 때 쓴 하네스**다. 스파이크가 아니라 **다시 돌릴 수 있는 증거**다 —
지적이 진짜인지 내 손으로 재현하고(고치기 전), 고친 뒤 같은 것으로 다시 재기 위한 것.
`decisions.md` ⑪ 과 `roadmap.md` "지금 어디인가" 의 숫자가 여기서 나온다.

표준 라이브러리만 쓴다(파이썬 3.9). 브라우저는 **헤드리스 크롬 152 를 CDP 로 몬다** — `cdp.py` 가
최소 웹소켓 + CDP 클라이언트고, 누르는 것은 `Input.dispatchMouseEvent` 로 낸 **진짜 마우스**,
치는 것은 `Input.dispatchKeyEvent` 로 낸 **진짜 키보드**다. `querySelector(...).click()` 이 아니다 —
그건 `pointerdown` 을 안 내서 확인 줄의 "밖을 누르면 그만둔다" 같은 것을 지나친다.

- 전부 **띄운 것을 끝에 죽인다.** 돌린 뒤 `pgrep -fl palmard` 로 확인해라.
- `prove.py` 는 환경변수를 셋 받는다: `PALMAR_TEST_PORT`, `PALMAR_CDP`, `PALMAR_NO_SHOTS=1`,
  그리고 `PALMAR_PY` 로 **데몬을 띄울 인터프리터**를 고른다 —
  `PALMAR_PY=/opt/anaconda3/bin/python3` 이 `AGENTS.md` 가 요구하는 "새 파이썬에서 한 번 더" 다.

  **고치기 전 판과 고친 뒤 판을 같은 조건에서 견줄 수 있다.**
